# Cove app downloads

Download the latest [Cove release](https://github.com/jvthomas702/Cove-updates/releases/latest) for macOS 14 or newer. The universal app supports Apple Silicon and Intel Macs.

This repository contains signed app archives, release notes and the signed update feed. Cove's source stays in its private repository. The app checks the feed daily; automatic installation is optional. Older Cove versions need one manual replacement with Cove 1.1.0 to gain the updater.

Update archives and feeds carry Ed25519 signatures verified by Sparkle. The app bundle is ad-hoc signed and is not Apple-notarized.

Feed: https://raw.githubusercontent.com/jvthomas702/Cove-updates/updates/appcast.xml
